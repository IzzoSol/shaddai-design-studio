# Lore fact-check (ORACLE + PIKADON)

1. **List the claims** in the copy, one per line, each with the exact number or quote.
2. **Verify each** with a web search (standard mode first). Prefer primary sources (Nobel, LoC, the paper, the company) over listicles. If Wikipedia is blocked, search for it.
3. **Grade:** confirmed → use it. Single secondary source → hedge it ("reportedly", "according to Cinema Cats") and link the source. Unverified → cut it, or ask the user.
4. **Catch mix-ups in user-supplied images:** the "Asimov with his cat" photo was Ray Bradbury. Say so kindly and use it correctly.
5. **Market/vendor stats from screenshots** (e.g. "AI consulting $11B → $91B", "34K certified consultants"): treat them as marketing claims. Don't put them in brand storytelling unless they're sourced and on-theme.
6. **Credits:** artists, studios, film excerpts. An unknown artist means asking the user. Never guess.
7. **Disclaimers:** "not affiliated with …" for every brand, label fiction as fiction, and add a not-financial-advice line on token sites.
8. Put a **Sources** list in the script/README and link sources on the page where the claim appears.

Examples from the $ASIMOV build: Three Laws first stated in "Runaround" (1942); Tesla's cat Mačak (his 1939 letter, via CBC); *The Boxing Cats* (Edison, 1894); Félicette (18 Oct 1963); Google's 2012 cat network (16,000 cores) and the Stanford + NVIDIA GPU network (2013, 6.5× bigger); the *I, Robot* cat "reportedly" named Asimov.
