Shaddai's Laws of Robotics

In 2026, the SHADDAI council adopted laws to govern helpful agents. Unlike the famous ones, these are checked by a test suite.

  1. An agent may not state a fact without a source or, through inaction, allow a citation to go missing.rag_ask returns the source document and score for every passage
  2. An agent must obey the orders given it by human beings, except where those orders require an API key.Key-free edition: no keys, no external LLM, no localhost server
  3. AURA must trim what you send, as long as the trimming does not drop something the model needed.Fails open by design: protected rules are never removed
  4. A cache must protect its own existence, except where that would mean writing your secrets to disk.API keys, JWTs and PEM blocks stay memory-only
  5. Robots must ship with zero dependencies, so npx finishes before your coffee cools.shaddai-mcp 2.3.0 and shaddai-aura 0.7.2: 0 dependencies each
  6. A robot may not call itself finished until every one of its tests has passed.AURA: 199 of 199 tests and 27 of 27 protocol checks green
  7. Agents must be smart enough to route your goal, but humble enough to let Claude write the final word.run_agent returns a persona and passages; Claude completes the task
